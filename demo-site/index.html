🔌 MCP 集成架构
Server：https://mcp.mcd.cn（Streamable HTTP · 无状态 · Bearer Token 鉴权 · 限流 600 次/分钟，内置 100ms 节流）。安全红线：只读 + 一键领券，绝不真实下单。
读
query-nearby-stores
找店

读
query-meals
菜单
15 分类 118 餐品映射表，价格是「元」（字符串）
读
query-store-coupons
门店可用券
每券带 couponId / couponCode / products[]，优化器输入
读
calculate-price
真实算价 ⚖️
优化器的唯一「裁判」，逐商品挂券，价格单位是「分」
写·领券
auto-bind-coupons
一键领券
自动领取全部可领券（唯一写操作，实测 7 张）
读
